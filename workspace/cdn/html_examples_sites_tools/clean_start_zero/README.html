The aim of the setup

💡 Aligning styles of a site, the single file `clean_start_zero__site.css` of three hundred ( 300 ) code lines of filesize eight kilobytes ( 8k ).

The zero css clean start sets just the few styles for the tags html, head, body, main or site.

The `clean_start_zero__base.css` file of smaller size solves just the base aligning.

Examples

html example 

1:  <html language="en" class="clean_start theme_fonts_a">
    
1:  <html language="en" class="<Your Namespace> clean_start theme_fonts_a">

css example 

1:  .<Your Namespace>.clean_start {
2:    --clean_start--all_tags--font-size:     0.94rem;
3:  }
