Current state

The web server is stable now, and the work on implementation of HTTP/3 goes on. The server can host web contents and PHP applications, provides the way to build fast and easily json endpoints getting data from different databases. The short summary of outstanding Jaisocx advantages is listed on the home page.

Monetization

The main auditorium of our server are the publishers of php applications, and web content, built with modern JS frameworks, like ReactJS, Angular or VueJS.

The payment will be charged for enabling HTTP/3 protocol on monthly or yearly basis. Otherwise customers' instances would serve sites under HTTP/1.1 and HTTP/2.
